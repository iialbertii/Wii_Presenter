# Wii_Presenter

Hi! I wanted to find another purpose for my Wiimote so I decided to vibecode it since I don't know how to work with Nintendo Hardware yet.
I hope whoever stumbles upon this finds it useful!

Requirements:
* Device (preferably a PC/Laptop, I havent checked for Mobile)
* Bluetooth

Commands for Pairing :
1. This step is for pairing the Wiimote to your desktop
     #####  ```py .\pair_wiimote.py```
2. This step is for "translating" the inputs from the Wiimote(customizble from the source code)
     ##### ```py .\presenter_mvp.py```
